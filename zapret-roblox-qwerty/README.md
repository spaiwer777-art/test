# roblox-qwerty.bat

Профиль Zapret (zapret-discord-youtube 1.10.3, winws v72.9) для Roblox у провайдера **QWERTY** (Москва).

QWERTY — бывшая сеть «Центрального Телеграфа», сейчас входит в группу Ростелекома, поэтому трафик фильтруется теми же ТСПУ.

## Установка
1. Положи `roblox-qwerty.bat` в папку `zapret-discord-youtube-1.10.3` (рядом с `bin`).
2. Закрой другие `general*.bat` и удали сервис zapret, если он установлен (`service.bat` → Remove Services). Одновременно может работать только один `winws.exe`.
3. Запусти `roblox-qwerty.bat` (сам запросит права администратора), потом запускай Roblox.

## Стратегии
| № | Основа | Когда пробовать |
|---|--------|-----------------|
| 1 | `general (EXP)`: fake + multisplit, seqovl 480 | по умолчанию, лучший результат в твоих тестах |
| 2 | `general (ALT11)`: seqovl 664, 8 повторов | если 1 перестала работать |
| 3 | hostfakesplit (`ozon.ru`) | если не грузятся текстуры (`rbxcdn.com`) |
| 4 | fake TLS с SNI `www.google.com` | запасной вариант |

Другую стратегию запускай из `cmd`: `roblox-qwerty.bat 2`.

## Что обходится
* HTTPS (TCP 80/443) для доменов Roblox: сайт, вход, API, текстуры, капча Arkose.
* UDP 49152-65535 к игровым серверам Roblox (AS22697, `128.116.0.0/17` и др.) — от ошибки 279 и бесконечной загрузки. Этих подсетей нет в `lists/ipset-all.txt`, поэтому стандартные `general*.bat` их не обрабатывают. Fake только на первые пакеты (`cutoff=n3`), пинг в игре не страдает.

## Если не помогает
* Включи DNS-over-HTTPS (Windows 11: Параметры → Сеть → DNS, например `1.1.1.1` или `9.9.9.9` с шифрованием) — DNS провайдера может подменять ответы.
* Проверка: `utils\test zapret.ps1` подхватывает и этот батник (тестирует стратегию 1).
