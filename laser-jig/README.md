# Рамка (джиг) для гравировки визиток

- `business_card_jig_2x3_90x50.stl` — плита 205.2 × 179.8 × 3 мм, 6 карманов под визитки 90×50 мм.
- `business_card_jig_2x3_90x50_layout.svg` — шаблон с положением визиток (1:1, мм) для LightBurn/LaserGRBL.
- `make_jig.py` — генератор: поменяйте параметры вверху файла (размер визитки, зазор, кол-во карманов) и запустите `python3 make_jig.py`.

Карман 90.6 × 50.6 мм (зазор 0.3 мм), глубина 0.8 мм. Пальцевые выемки по коротким сторонам, угловые подрезы — визитка садится в угол без упора в скругление.
Печать: PLA/PETG, слой 0.2 мм, без поддержек, плоской стороной вниз.
